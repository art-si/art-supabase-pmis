# 亿企工场 PMIS

面向设备点检、巡检、保养、维修与能耗治理的独立设备管理应用。

本仓只维护 PMIS 业务页面、领域规则和 API；认证、租户、动态菜单、权限、主题与 Supabase 公共运行时由 `art-supabase-pro` 提供。设备点检和设备巡检沿用既有菜单名称与层级，不在应用拆分过程中改变业务语义。

## 本地运行

```powershell
pnpm install
pnpm dev
```

默认地址：`http://localhost:3020`。
